# 网课助手：三个课程工具的统一启动器

把三个工具收到一个界面里：选平台、填几个选项、点开始，进度在页面上看。

| 平台 | 工具 | 仓库 |
| --- | --- | --- |
| 学习通 | Playwright 版 | [xuexitongScript](https://github.com/lmmmp-17/xuexitongScript) |
| 长江雨课堂 | Playwright 版 | [yuketang](https://github.com/lmmmp-17/yuketang) |
| 智慧树 | Autovisor | [Autovisor](https://github.com/lmmmp-17/Autovisor) |

三个仓库自己的入口脚本（`start.cmd` / `run.cmd`）照旧能用，这个启动器只是在它们外面包了一层。

## 一、初级使用教程

### 1. 准备（只做一次）

- **Node.js 20 或更新**。Windows 上没装的话，`start.cmd` 会问你要不要用 winget 装。启动器本身**没有任何 npm 依赖**。
- **把要用的工具仓库下载下来**，和本项目按下面的位置放好（只用其中一两个平台的话，只下那几个就行）：

  ```
  某个目录/
  ├── launcher/          ← 本项目
  ├── yuketang/
  ├── Autovisor/
  └── ../xuexitongScript/
  ```

  放在别处也行，见进阶教程里的「仓库放在别处」。

### 2. 启动

| 系统 | 怎么启动 |
| --- | --- |
| Windows | 双击 **`start.cmd`** |
| Linux / macOS | **`./start.sh`** |

它会在本地开一个控制台，并用**你平时用的浏览器**打开。没自动弹出来的话，把终端里打印的那条地址整条复制过去。

### 3. 使用

1. 在页面顶上选一个平台。
2. 按需要改几个选项。不改就用默认的：静音、切到最高倍速、自动选浏览器。智慧树必须填**课程地址**（课程播放页，能直接看到视频的那一页）。
3. 点**开始**。页面上会提示接下来要你做什么（比如在打开的浏览器里登录、点开一节课），运行状态和日志都在下面实时显示。
4. 要停就点**停止**。

## 二、注意事项

- 控制台和播放视频的不是同一个浏览器窗口。播放视频的那个窗口**别最小化**，也别在里面切到别的标签页；被别的窗口盖住没关系。
- 控制台页面切到后台也没关系，标签页的标题和小图标会显示在跑、停了还是出错。
- 取消勾选「静音」会直接外放声音，在教室、宿舍里注意。
- 平台名字是灰色的，说明没找到那个工具的仓库。鼠标移上去能看到它找的是哪个路径，照「准备」里的位置放好，或者看进阶教程。
- 页面提示「和启动器断开了」：多半是终端窗口被关掉了，重新启动一次。

## 三、进阶教程

### 仓库放在别处

建一个 `tools.local.json`（已在 `.gitignore` 里），写上实际路径：

```json
{
  "xuexitong": "D:\\code\\xuexitongScript",
  "yuketang": "D:\\code\\yuketang",
  "autovisor": "D:\\code\\Autovisor"
}
```

### 命令行参数

在 `launcher` 目录下执行 `node run.mjs [选项]`：

| 参数 | 作用 |
| --- | --- |
| `--port <端口>` | 指定本地端口，默认随机 |
| `--no-open` | 不自动打开浏览器，只打印地址 |
| `--help` | 显示说明 |

### 加一个工具

改 `src/tools.mjs` 里的登记表，加一条就行，界面是照着这张表画出来的。两类：

- `kind: 'flags'`：选项通过命令行参数传（学习通、雨课堂这种）
- `kind: 'config'`：选项写进配置文件，再运行入口脚本（Autovisor 这种）

选项可以按平台限制（`platforms`），单选里的某一项也可以（比如 Chromium 只在 Linux 上出现），默认值也可以按平台给（`platformDefault`）。

## 四、有价值的技术细节

### 为什么控制台不开在专用浏览器里

那些工具要靠课程页的 `document.visibilityState` 保持 `visible` 才能持续播放，而这一项没法模拟。控制台要是跟课程页同在一个窗口里，你一切过去，课程页就变成后台标签了。所以控制台总是开在系统默认浏览器里，和脚本启动的专用 Chrome / Edge 分开。

### 配置文件怎么合并（智慧树）

- 只改界面上填了的项，注释和没动过的项原样保留。
- **留空 = 保持原样**。不然没填密码就会把配置里存着的密码清掉。
- 键名不分大小写。configparser 写回文件时会把键名全转成小写（上游 `GUI.py` 存过的配置就是 `enablehidewindow` 这样），按原样比的话会再追加一行同名键，configparser 读到重复键直接报错。
- 打开页面时会读已有配置来预填表单，密码不往页面上送。

### 控制台接口

界面是纯静态的 `public/index.html`，后端只有这几个接口，想整体重做界面不用动后端：

| 接口 | 作用 |
| --- | --- |
| `GET /api/tools` | 工具登记表 + 当前运行状态 |
| `GET /api/events` | SSE：`state` / `started` / `status` / `line` / `exit` |
| `POST /api/start` | `{ tool, values }`，失败返回 `{ error }` |
| `POST /api/stop` | 停掉正在跑的那个 |

所有接口都要 `?token=`，token 在启动时随机生成、打印在那条地址里。原因是这个服务能在你机器上启动进程——本机任何一个网页要是能随便调它就太糟了。服务只绑 `127.0.0.1`。

工具输出里以 `[[status]] ` 开头的行会被当成「当前在干什么」单独显示，其余按日志走。工具没有这个前缀时界面就拿最新一行日志当状态，功能照常。

Windows 上入口是 `.cmd`，要经过 `cmd.exe` 启动，直接结束子进程只会结束外层的 `cmd.exe`，真正在播的 node / python 会留在后台。所以「停止」用 `taskkill /T /F` 连整个进程树一起结束，代价是工具来不及打印收尾总结。
