## 1. 这是什么

「网课助手」是一个装在学生自己电脑上的小工具，用来同时管理三个网课平台的自动播放：学习通、长江雨课堂、智慧树。

用户在这个控制台里：

1. 选平台；
2. 改几个选项（多数人不改）；
3. 点「开始」。

之后工具会打开一个**单独的浏览器窗口**播放课程视频。控制台负责显示每个平台在干什么、跑了多久、出了什么问题，以及「停止」。

- **用户**：在校学生，很多是第一次用这种工具的新手。全中文界面。
- **使用场景**：开着放在一边，偶尔切过来看一眼进度。常常是**三个平台同时在跑**。
- **最重要的事**，按优先级：
  1. 一眼看出每个平台是在跑、停了，还是出错了；
  2. 出错时告诉用户下一步怎么做；
  3. 开始之前不要让新手面对一堆看不懂的选项。

## 2. 形态

- **Windows 桌面独立窗口**：内嵌 WebView2，Chromium 内核，没有浏览器的地址栏和标签栏。
  - 窗口标题由系统画，页面里**不需要**再画标题栏。
  - 默认 **960×720**，最小 **720×560**，可以拉伸。
- **浅色和深色都要**，跟随系统（`prefers-color-scheme`）。
- **只做桌面**，不需要适配手机。
- 另有一个终端版界面（TUI），由开发者按同样的信息结构自己做。如果你愿意，可以附一份终端版的布局草图（见第 7 节第 6 项）。

## 3. 信息结构和每一个状态

文案请用下面这些**真实内容**，不要用占位文字。

### 3.1 平台切换（始终可见）

- 三个平台：**学习通**、**长江雨课堂**、**智慧树**，任何时候都能切换。
- 切换只是换「正在看哪个」，**不影响**其它平台在跑。
- 每个平台名旁边要能看出它的状态：
  - **在跑**：显示已运行时长，比如 `▶ 12:34`；
  - **中途出错停了、用户还没切过去看**：用错误色标出来，比如「停了」；
  - **空闲 / 正常结束**：不加标记。
- 某个平台的程序目录不在（被删了或没下载全）：平台名置灰或划掉，鼠标悬停时显示它找的路径。

### 3.2 一个平台：没在跑时（表单）

**每个平台的说明**放在表单上面，告诉用户点开始后要做什么：

- 学习通：会自动打开一个专用的浏览器窗口。在里面登录学习通，点开课程的任意一节，脚本就开始。
- 长江雨课堂：会自动打开一个专用的浏览器窗口。在里面登录雨课堂，点开课程里任意一个视频，脚本就开始。
- 智慧树：会自动打开一个浏览器。在里面登录智慧树，点开要学的课程（进到能看到视频的播放页），脚本就开始。

**表单字段**，按顺序列出。字段的类型、默认值和说明文字都是确定的：

**学习通**
- 最多播几节｜数字，可留空｜占位「留空 = 不限」
- 倍速｜单选：最高 / 不改，默认「最高」｜说明「最高 = 播放器倍速菜单里能选的最高一档」
- 静音｜勾选，默认勾上
- 遇到只剩测验的小节就停下｜勾选，默认不勾｜说明「默认是跳过去找下一个有视频的小节」
- 浏览器｜单选：自动 / Chrome / Edge，默认「自动」｜说明「自动 = 装了 Chrome 就用 Chrome，没有就用 Edge」

**长江雨课堂**
- 最多学几项｜数字，可留空｜占位「留空 = 不限」
- 倍速｜单选：最高 / 不改，默认「最高」｜说明同上
- 只看视频，跳过图文｜勾选，默认不勾
- 静音｜勾选，默认勾上
- 浏览器｜单选：自动 / Chrome / Edge，默认「自动」｜说明同上

**智慧树**
- 倍速｜单选：最高 / 不改，默认「最高」｜说明同上
- 每门课最多跑几分钟｜数字，默认 30｜说明「0 = 不限」
- 静音｜勾选，默认勾上
- 浏览器｜单选：Edge / Chrome，默认「Edge」｜说明「选电脑上装着的那个」
- 把浏览器窗口移出屏幕｜勾选，默认不勾｜说明「看不见但照常播放。报窗口句柄错误时取消勾选」
- 自动完成登录滑块｜勾选，默认不勾｜说明「填了手机号和密码才用得上；第一次勾上会多装 numpy、opencv」
- 手机号｜文字｜占位「留空则在浏览器里手动登录」
- 密码｜密码框｜占位「留空则在浏览器里手动登录」

**表单相关的规则**：

- **「静音」很重要**：用户可能正在教室里。取消勾选时立刻显示醒目的警告：「取消静音后视频会外放声音」。
- **新手大多什么都不改**，直接点开始。表单可以考虑「常用的在前、不常用的收起来」，但不能藏掉「静音」。
- **主按钮**：「开始：学习通」（随平台名变化）。点下去到真正启动之间显示「正在启动…」。
- 启动失败时（比如参数不对），在按钮旁边显示错误原因。

### 3.3 一个平台：在跑时

- 表单收起，换成一行「这次的设置」摘要。比如「倍速 最高，静音，浏览器 自动」。没开静音时，摘要里要用错误色写「会外放声音」。
- **当前状态**：一句话，取工具日志的最新一行，比如「⏳ 等你打开课程播放页…（已等 12 秒）」「正在播放：1.3 函数的极限」。这是页面上最显眼的东西。
- **已运行时长**，每秒更新。
- **提醒**：「播放视频的那个浏览器窗口别最小化，也别在里面切到别的标签页；被别的窗口盖住没关系。」
- **日志**：每行带时间，可以滚动，最多 1000 行。在底部时自动跟着滚，用户往上翻了就不要打扰他。日志分三种：普通、警告、错误，警告和错误要能区分出来。
- **按钮**：「停止：学习通」。点下去后显示「正在停止…」，最多可能要等 8 秒。

### 3.4 一个平台：结束之后

- 用户点停止的：「学习通 已停止」。
- 自己跑完的：「学习通 跑完了」。
- 中途出错的：「学习通 中途停了，退出码 1。原因一般在下面最后几行」。要显眼，用错误色。
- 日志留着；表单重新出现，可以再次开始。

### 3.5 全局状态和提示

- **第一次运行要装依赖**：学习通、雨课堂第一次跑会先装一个 npm 包，智慧树会先准备 Python 环境。可能要等一两分钟，日志会一直有输出。界面上要让人知道「在准备，不是卡死了」。
- **和后端断开**（后端进程意外退出）：「和启动器断开了。」再加一句怎么办：「关掉这个窗口重新打开网课助手。」
- **另一个入口正在运行**：网课助手同时还有终端版，两者不能同时开。打开窗口时如果终端版在跑，显示：「终端版的网课助手正在运行，先在那边退出，再打开这个窗口。」
- **关窗口时还有平台在跑**：确认「还有 2 个平台在跑，关掉窗口会把它们都停掉。」，按钮「全部停止并关闭」/「取消」。这个确认框可能由系统原生弹出，你给出文案和建议的样式即可。
- **窗口标题**（由系统画，你只提供文案规则）：
  - 一个在跑：「▶ 学习通 12:34」；
  - 多个在跑：「▶ 学习通、智慧树」；
  - 有出错：「✕ 学习通 停了（还有 1 个在跑）」；
  - 都没在跑：「网课助手」。

## 4. 约束

- **单个静态 HTML 文件**，CSS 写在里面，不依赖任何外部字体、图标库或 CDN。电脑可能没网。
- **字体**用系统自带的中文字体：Windows 是「Microsoft YaHei UI」，再往下回退。不要引入网络字体。
- 键盘可以完整操作，焦点要看得见；尊重 `prefers-reduced-motion`。
- 动效克制：只在「状态变化」时有一下，不要到处 hover 动画。
- **不能出现「刷课」这个词**。说「网课」「课程」「学习」。
- 文字简洁、口语化，不用感叹号，不说「您」。

## 5. 数据从哪来（实现时会把假数据换成这些）

后端是本机的 HTTP 服务，界面通过下面几个接口拿数据。设计稿里用假数据就行，但请让每个状态都能对上这里的字段。

- `GET /api/tools`：三个平台的登记信息（名字、说明、表单字段），加上每个平台当前的运行状态 `{ running, startedAt, values, status, lines, exit }`。
- `GET /api/events`（SSE 实时事件），每条都带 `tool`（是哪个平台）：
  - `started`：开始了，带 `startedAt` 和这次用的设置 `values`；
  - `status`：工具主动报告的当前状态（一句话）；
  - `line`：一行日志，带 `line`、时间 `at`，以及是不是错误输出 `err`；
  - `exit`：结束了，带 `code`（退出码）和 `stopped`（是不是用户点的停止）。
- `POST /api/start {tool, values}`：开始，失败时返回 `{ error }`，比如「学习通 已经在跑了，先停掉它」。
- `POST /api/stop {tool}`：停止。

## 6. 现有设计

现在的界面叫「作业本」：页面像一张横格作业纸，左边页边放字段名和时间；**荧光笔**只标「现在正在发生的事」（选中的平台、当前状态），**红笔**加波浪线只标错误。截图在 `design/reference/`。

你可以沿用这个方向，也可以换掉，由你判断。但第 3 节列的**信息和状态一个都不能少**。

## 7. 请交回来的东西

1. **`console.html`**：单文件、能直接用浏览器打开的原型。
   - 里面放假数据，还要有一个**状态切换器**（可以是页面角落的一排小按钮），能切出第 3 节的每一个状态：
     - 空闲；
     - 三个平台同时在跑；
     - 正在启动；
     - 第一次装依赖；
     - 正常结束；
     - 出错结束；
     - 取消静音的警告；
     - 程序目录不在；
     - 和后端断开；
     - 终端版正在运行；
     - 关窗口确认。
   - 浅色、深色都能看。
2. **`tokens.md`**：颜色（浅色和深色各一套，写出用途）、字号层级、间距、圆角。终端版会参照这里的配色。
3. **`icon.svg`**：应用图标，用在 exe 文件和窗口标题栏，16px 下要能看清。
4. **`screens/`**：每个状态在 960×720 和 720×560 两种尺寸下的截图。
5. **文案改动清单**：如果你改了任何界面文字，列出「原文 → 新文」。
6. **（可选）`tui.txt`**：终端版的布局草图。
   - 等宽 100 列 × 30 行，中文占两列；
   - 不要用框线字符（┌─┐）：中文 Windows 控制台会把它们画成两列宽，布局会错位；
   - 只能用 16 种终端颜色。
