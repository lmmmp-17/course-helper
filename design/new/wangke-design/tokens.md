# 网课助手 · 设计 tokens（作业本 第二版）

一张作业本内页。三支笔各管一件事，外加一支铅笔：

| 笔 | 管什么 | 不许拿来干什么 |
|---|---|---|
| 蓝黑墨水 `ink` | 正文、主按钮 | — |
| 荧光笔 `hl` | **现在正在发生的事**：选中的平台名、当前状态那一行 | 装饰、hover、普通强调 |
| 红笔 `pen` | 错误：停了、中途停了、启动失败、漏填、会外放声音 | 普通提醒 |
| 铅笔 `pencil` | 日志里的「注意」（stderr 或 `[WARN]`） | 错误（错误一律红笔） |

## 颜色

所有文字色都按 WCAG 4.5:1 对作业纸 `page` 校过。

| token | 浅色 | 深色 | 用途 | 对 page 对比度（浅 / 深） |
|---|---|---|---|---|
| `paper` | `#E9EDF1` | `#10151E` | 窗口底色（作业纸后面的桌面） | — |
| `page` | `#FAFBFC` | `#171E2A` | 作业纸 | — |
| `ink` | `#1E2B4A` | `#DDE4EE` | 正文、平台名（选中 / 在跑）、主按钮底色 | 13.5 / 13.1 |
| `ink-soft` | `#55637D` | `#A0AEC1` | 页边字段名、说明文字、没选中的平台名、设置摘要 | 5.9 / 7.4 |
| `ink-mute` | `#626F86` | `#8391A6` | 日志时间、占位符、没找到的平台 | 4.9 / 5.2 |
| `rule` | `#D8E1EA` | `#232D3E` | 横格线（每 28px 一条） | 装饰 |
| `rule-strong` | `#B4C4D6` | `#36445C` | 页边竖线、纸张边框、小按钮描边 | 装饰 |
| `hl` | `#F2E35B` | `rgba(232,214,72,.36)` | 荧光笔，文字仍用 `ink` | — |
| `pen` | `#C2362F` | `#F27D70` | 红笔：错误文字、波浪下划线、危险按钮底色 | 5.3 / 6.3 |
| `on-pen` | `#FFFFFF` | `#1A0F0E` | 红底按钮上的字 | 5.4 / 7.1 |
| `pencil` | `#8F5208` | `#E3A857` | 日志里的「注意」行 | 6.0 / 8.0 |
| `scrim` | `rgba(30,43,74,.38)` | `rgba(5,8,14,.6)` | 对话框后面的遮罩 | — |

「注意」和「出错」不只靠颜色区分：注意行前面有 `!`，出错行前面有 `✕` 而且加粗。

## 字体

```
--sans: "Microsoft YaHei UI", "Microsoft YaHei", "PingFang SC", "HarmonyOS Sans SC", "MiSans",
        "Noto Sans CJK SC", "Source Han Sans SC", system-ui, sans-serif;
--mono: "Cascadia Mono", Consolas, "Noto Sans Mono CJK SC", ui-monospace, monospace;   /* 只用在路径上 */
```

数字一律 `font-variant-numeric: tabular-nums`，计时器跳秒时不抖。

| 层级 | 字号 / 字重 | 行高 | 用在 |
|---|---|---|---|
| 状态 | 22 / 600 | 56（两格） | 当前状态那一行、结束语 |
| 平台名 | 22 / 600（窗口窄于 860px 时 20） | 28 | 抬头的三个平台 |
| 小标题 | 17 / 600 | 28 | 对话框标题 |
| 正文 | 15 / 400 | 28 | 说明、表单、日志 |
| 书名 | 15 / 700 | 28 | 页边的「网课助手」 |
| 按钮 | 15 / 600 | 40 高 | 开始、停止 |
| 小字 | 13 / 400–600 | 28 | 字段说明、日志时间、平台名下的状态、「最新一行 …」 |

## 间距

所有东西落在 28px 的格线上：一行字一格，块与块之间空一格。

| token | 默认 | 窗口窄于 860px | 说明 |
|---|---|---|---|
| `line` | 28px | 28px | 格线，基础单位 |
| `pad` | 48px | 28px | 作业纸左右内边距 |
| `margin` | 9em（135px） | 6.5em | 页边栏宽，右对齐 |
| `gap` | 28px | 20px | 页边栏和正文之间 |
| 窗口边距 | 上下 28，左右 20 | 左右 12 | 窗口高度小于 640px 时上下 12 |
| 按钮 | 高 40，左右 1.6em | | 上下各留 8px，正好占两格 |
| 小按钮 | 高 24，左右 0.8em | | 「回到最新」 |

日志框的高度 = 窗口剩下的高度，按整行取，最少 4 行。

## 圆角

| 东西 | 圆角 |
|---|---|
| 作业纸 | 2px |
| 按钮、小按钮 | 3px |
| 对话框 | 4px |
| 荧光笔 | 不规则：`.35em .6em .4em .7em / .5em .4em .6em .5em`，像手画的 |

## 动效

只有两处，都只在状态变化时出现一次；`prefers-reduced-motion` 下全部关掉。

- 荧光笔画上去：0.5s，`cubic-bezier(.3,.7,.2,1)`。触发：切换平台、开始、工具报了新阶段（换了一节）。日志一行一行来时不画。
- 「改设置」的小箭头翻转：0.2s。

## 窗口标题

| 情况 | 标题 |
|---|---|
| 一个在跑 | `▶ 学习通 12:34` |
| 多个在跑 | `▶ 学习通、智慧树` |
| 有出错（没切过去看过） | `✕ 智慧树 停了（还有 1 个在跑）`；没有别的在跑时去掉括号 |
| 和启动器断开 | `✕ 和启动器断开了` |
| 都没在跑 | `网课助手` |

## 终端版对照（16 色）

| token | 终端 |
|---|---|
| `ink` | 默认前景 |
| `ink-soft` / `ink-mute` / `rule` | 亮黑 90 |
| `hl` | 黑字 30 + 黄底 43 |
| `pen` | 红 31，加粗 |
| `pencil` | 黄 33 |
| 主按钮 | 白字 97 + 蓝底 44 |
